# Integrated V3.1 Validation Report

Integrated V3.1 is a minimal patch over Integrated V3.0.

## Intended behavior change only

1. `package.status = unresolved` no longer blocks Canonical Bundle creation.
2. Canonical `product.json` records `package: null` and `package_status: unresolved` for that exception.
3. Phase 4 accepts the bundle and creates only the WooCommerce `Part Number` attribute when package is unresolved.
4. The Publisher `attributes` step is considered successful when the Part Number-only exception is completed correctly.
5. Excel Report keeps `Phase 4 = successful` when all actual required publishing steps succeed.
6. The `P2 Package` cell shows `unresolved` and is highlighted red independently from the Phase 4 result.
7. Resolved-package behavior remains unchanged: both `Part Number` and `پکیج` attributes are written.
