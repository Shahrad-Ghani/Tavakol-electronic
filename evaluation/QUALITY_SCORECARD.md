# Quality Scorecard

Phase 3 Altimate V1 separates operational disposition from quality measurement.

## Primary quality dimensions

### Fact extraction
- useful fact count
- priority coverage
- Golden precision / recall when a manual reference exists
- wrong value/unit/sign rate during manual regression
- variant leakage

### Content factuality
- hard gate
- local fact safety
- facts-only semantic audit
- unsupported claim count

### Usefulness
- usable technical table
- purchase/price section
- FAQ
- CTA
- available fact coverage actually suitable for a buyer

### Tone
- naturalness score
- style flags
- AI-like score is diagnostic only

### SEO
- score
- density
- word count
- structure contract

### Cost
- total cost/product
- PDF calls/product
- PDF fallback rate
- Expensive writer rate (0% in V2.1)

## Secondary operational metric

PASS / REVIEW rate is retained for workflow planning, but it is explicitly not a primary model-quality metric.
